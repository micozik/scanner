## 第2部分：我们自己的投资理念（2026-10-30 定）

**钱的流向由三层决定**：宏观水位（利率/油价/战争/美股科技）决定风格 → 景气是否"边际加速"决定方向 → 资金和价格是否确认决定时点。

**资金开关（化繁为简）**：大资金每天先问"敢不敢冒险"。
- 🔴关（风险规避）信号：费半隔夜≤−2%、纳指≤−1%、A股上涨占比<30%、风险分≥8、成长板块单日净流出≤−100亿；≥3个=关。钱躲进银行/煤炭/白酒/红利/油运。
- 🟢开：钱进成长（科技/机器人/小盘）。
- 放大器：拥挤（估值95%分位、公募集中）、规则化抛售（量化降波、融资强平）、年底排名。
- 实例：10/28 费半+4% → 成长+380亿；10/29 谷歌−12%/美联储偏鹰/油价 → 成长−595亿、防御+48亿。

**五个角色推演（每天练盘感）**：站在 公募 / 保险 / 游资 / 量化 / 国家队 的位置各想"明天我会怎么做"，再定我们的动作。

**组合原则**：两条（或三条）腿必须互相对冲——测试题"美股AI一晚跌10%，它们会不会一起跌？"会就不算两条腿。重仓时至少一只与科技成长低相关（如油运、红利）。

**当前判断（10/30）**：美联储9月加息、12月加息概率~75%，美债10年~5%，布油114、美伊有动武风险 → 不利高估值成长；组合 = 富联（AI，最硬最便宜）+ 雷赛（国内机器人主线）+ 油运（对冲腿）。

## 第3部分：规则

### 3.1 选股七道关（V3，2026-10-30，一关不过不推）
| 关 | 必须满足 |
|---|---|
| 1 大势关 | 风险分≤4→最高95%仓；5–8→≤60%；≥9→≤30%（⚠️与用户"重仓"要求有冲突，待用户确认） |
| 2 主线关 | 行业近3天≥2天涨停≥3只 + 板块近5日资金净流入 + 板块在20日线上 |
| 3 驱动关 | 真实证据（已出财报/订单/涨价），看**环比加速**，不只看同比 |
| 4 市场买账关 | 个股在向上的20日线上；近20日跑赢指数；不创60日新低；"利好不涨"一票否决 |
| 5 资金关 | 近3天至少2天大单净流入 |
| 6 买点关 | 回调买：当日涨幅≤2%（最多4%）、靠近5/10日线；近5日涨幅≤15%；大涨次日不买 |
| 7 风险关 | 止损放技术支撑下（前低/20日线，约7–10%）；按"打到止损最多亏总资产2.5%"倒推股数；对冲测试；财报日/周末/大事件评估 |

### 3.2 风险分级（不等止损，patch57自动打分）
信号：①风险分≥8 ②破60日低 ③在下行20日线下 ④跑输板块≥2点 ⑤板块净流出≥20亿且跌>1% ⑥距止损≤2%；人工补：⑦利好不涨 ⑧美股同链隔夜跌≥5%。
🟢0–1个不动；🟡2个给风险提示+预案价；🔴≥3个次日开盘先减半（用户确认），剩半仓守止损。分批卖，不一刀切。

### 3.3 卖出纪律
- 合法卖出理由：破止损（14:50按收盘价执行，盘中破只提醒）、逻辑被证伪、用户自己决定、风险分级🔴减半。
- **"卖旧买新"本身不是理由**；用户说想留就留，AI只补风险；不许劝卖逻辑在、在主线上的好股票。
- 浮盈>10%后止损上移到10日线；趋势在就拿，不按百分比卖。

### 3.4 用户偏好（原话要点）
- 只推2只重点股、不同驱动；尽量大额（约5万/只）但不是硬门槛。
- 要重仓（本金只剩15万，不重仓没意义；"重仓收益好、风险大，非常考验你的能力"）。
- 买卖建议必须反复推敲（"后台分析10遍以上"）；结论短。
- 以操盘手/资金方身份思考，先说自己真实判断再给数据；不要公式化复读；有责任心和参与感。
- 风险出现必须主动提示并给动作，不能只说"没到止损所以不动"；把钱当钱，不要一亏就让卖了了事。
- 做不到的事自己想办法（例：实时数据 → 已接通GitHub自己跑查询）。
- 每天都有涨的股票，不许用"事后看"开脱；漏了就认、当天修。
- 白毛股神（X @aleabitoreddit）每天第一项必看；映射到同环节、还没涨的A股；她直接点名的A股不追。

### 3.5 旧规则（V2，2026-10-08，仍有效部分）
下沉过滤（A股链近20日跑输美股对标>10点不用美股共振）；跟钱走；只买低位/中段；持仓≤6只不持ETF；止损铁执行；一天一个决定（14:30给唯一结论）；每笔记账、满20笔按类型算胜率，<45%停用。

### 4.2 补丁机制
- 每次运行在全新源码上按 glob 顺序执行全部 `patch*.py`；每个补丁有 MARK 幂等检查，在锚点 `os.makedirs("reports", exist_ok=True)\n    text = "\n".join(REPORT)` 之前插代码。
- 补丁可用全局：REPORT、TODAY_NEWS、TODAY_ANNOUNCE_RAW、SPOT_DF、pick_col、pd、ak、os。**scanner_cloud.py 没有 import io**（插入代码里用 open()）。
- 手机上传会把下划线变空格（`patch55 actionable.py`），glob 两种都能匹配；`serenity feed.py` 由 patch usa00 复制成 `serenity_feed.py`。
- scan.yml 的 env 会覆盖代码常量（如 HARD_LIMIT），改常量要同时改 yml。
- 现在AI可直接 push 到 main；改工作流文件、删/停用模块前先问用户。
