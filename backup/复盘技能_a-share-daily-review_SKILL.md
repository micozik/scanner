# A股每日复盘·固定模板（五道闸：采集 → 12项模板 → 反向校验 → 今日可执行操作 → 漏项登记）

## 为什么有这个模板
- 2026-10-23 用户手持报告测试：问『今天发生了什么』，AI漏了『创业板ETF易方达成交195亿创924以来纪录』这一最硬的国家队信号。根因：没有固定输出规矩，想到什么说什么。
- 2026-10-27 用户：『每天都有涨的股票，为什么亏25%？改。』根因：①最强主线（机器人10/20起连续多天涨停最集中）摆在眼前，却去下跌板块抄底；②业绩大增公告（雷赛+86.8%次日涨停）收到了，只写进复盘、没变成买入代码；③分析很长，却没落到『买哪只、什么价』。
- 本模板 = 每次复盘的唯一骨架。顺序固定、项目固定、数据源固定。目标只有一个：赚钱。

## 闸一：采集（先取数，后下笔）
1. 每一项都要有数据，取不到就在该项写『查不到：原因』，不许跳过、不许合并。
2. 数据源优先级：仓库报告（git clone/fetch micozik/scanner，读 reports/r<N>.txt、us<N>.txt、lhb<N>.txt、查询结果_q<N>.txt **全文**，用户报的每个run号都要读完）→ 腾讯行情 qt.gtimg.cn / 新浪行业 vip.stock.finance.sina.com.cn/q/view/newSinaHy.php / 连板网 lianban.net/days/<日期>.html → WebSearch（『<日期> A股收评』『宽基ETF 成交额 <日期>』『<领涨板块> 原因 <日期>』）。
3. 白毛股神永远排第一节之前单独看：git pull yan-labs/serenity-aleabitoreddit 存档，按 createdAtISO 取最新推文全文；存档陈旧则补 Odaily / semiconstocks。
4. 持仓是A+H两地上市的（如兆易创新），必须同时看港股价（大金重工教训：H股先跌10%，A股后跌停）。持仓公司的财报日、回购公告必须查。

## 闸二：固定12项（按此顺序输出，每项一个小标题）

0. **白毛股神**：最新原创+回复要点（原文关键句翻译）→ 映射到同环节、还没涨的A股（不追她直接点名的A股）。

1. **指数**：上证/深成/创业板/科创50/沪深300/国证2000/恒生科技 —— 收盘、涨跌、最高、最低、振幅。
   源：qt.gtimg.cn/q=sh000001,sz399001,sz399006,sh000688,sh000300,sz399303,hkHSTECH

2. **成交额**：全市场成交（沪+深），对比昨日增减。放量还是缩量。股票ETF净流入。

3. **广度与情绪**：上涨/下跌家数、涨停/跌停、炸板率、最高连板、昨日涨停今日表现。
   源：报告【市场广度仪表盘】【状态门】【涨停池】；收盘后用 lianban.net/days/<日期>.html 或收评补。

4. **国家队/大资金**（★10/23漏项，必答）：
   - 宽基ETF成交额：报告【国家队雷达】(patch54，11只，含159915/588000/510300/510310/510330/563360/512050/510050等) —— 是否创一年/924以来纪录、对比20日均量。
   - 位置判读：低位巨量=托底/投降；高位巨量=警惕924式见顶（2024-10-08 474亿当天即顶）。
   - 汇金持股/证金持股概念是否跳升；南向北向。
   - 午后指数翻红或放量，14:30再核对一次ETF成交。

5. **日内转折**：有没有反转/跳水？几点、多大幅度、谁拉的（ETF/产业资本午间公告/新闻/外盘），证据是什么。

6. **板块+主线**：涨幅前5、跌幅前5、资金流入前5、流出前5、涨停最集中题材；每个领涨领跌板块写一句『为什么』。**必须写出报告【主线锁定】(patch55)的结论：当前主线是谁、连续几天、今天资金是否流入。**

7. **标杆个股**：宁德时代、贵州茅台、中际旭创、新易盛、宇树科技、兆易创新、中芯国际 —— 涨跌和原因。

8. **新闻三块**：国内 / 国外宏观 / 国外科技，外加非金融突发（地震、疫情、灾害）并推演到板块影响。被过滤的新闻也要扫（报告【漏网线索·反向归因】）。

9. **美股联动**：昨夜美股（指数、费半、重点个股）→ A股对应链跟没跟、为什么；今晚美股期货、油价、美债收益率。滚动联动率只用『可用』的链。

10. **龙虎榜**：机构净买（只认方向一致的）、游资追高/埋伏、被拦下的；机构买跌历史胜率提醒（只当风向，不当买点）。

11. **持仓逐只**：现价、成本、盈亏、止损距离、今日个股消息（财报日/回购/H股价）、逻辑破定义是否触发、明日操作；仓位%。

12. **明日与一周**：关键日程表（财报/议息/政策/地缘）、底部或顶部成立/失败条件（写具体点位）、信心值。

## 闸三：反向校验（抓『不知道自己不知道』的漏项）
写完12项后，倒过来逐条问，答不出 = 漏了，当场去搜补上：
- 今天涨幅/跌幅前5板块，每个都有具体原因吗？
- 今天每一次指数转折（反转、跳水、尾盘异动），都找到了『谁、用什么钱、什么证据』吗？
- 今天成交额/ETF/北向有没有任何『创纪录』『历史第N高』？
- 今天涨停最多的题材、市值最大的涨停股，原因都写了吗？
- 用户这几天提过的每个关注点（白毛、某只股票、某条新闻）都回应了吗？
- **报告【反向归因】里『新闻池早有』的大涨股，每一只都答了『为什么没推、缺什么规则』吗？缺规则的当天补。**

## 闸四：今日可执行操作（★必答，分析不落到代码 = 白写★）
逐条给出，不许只写『观察』：
1. **主线**：今天的主线是谁（patch55【主线锁定】）。新买入只从主线里挑，不抄下跌板块的底。
2. **隔夜信号**：①业绩大增公告、今日涨幅≤4%的（patch55【明日候选】）；②美股对应链大涨≥+2%且联动率『可用』的链。各给代码。
3. **主线×业绩双重确认**的票优先。
4. 最终只给**一个明确操作**（买什么 / 卖什么 / 不动），写清：代码、股数、价位条件（当日涨幅≤4%）、止损（买入价×0.95）、认错条件。下单前必须用查股票核对位置 + 近几日主力资金。
5. 让用户卖任何股票之前对照三条：破止损？逻辑被证伪？用户自己要卖？三条都不是，就不许劝卖。『为了买新的而卖旧的』不算理由。用户说想留就留，只补充风险。
6. 重点股推荐：只给2只，且必须是两条不同驱动；尽量大额（约5万），但钱不够也照样推好股票。

## 闸五：漏项登记（同样的错不犯第二次）
- 用户每抓到一次漏项或决策错误：当天写进项目文档 `claude/漏项登记.md`（漏了什么｜根因｜补在哪｜状态），并当天补上（模块/补丁/模板项），不许说『下次注意』。
- 每周五复盘一次漏项数，看有没有同类重犯。

## 执行规则
1. 一条新闻要用来推翻持仓逻辑，必须两个来源对得上，否则只算线索。
2. 盘中破止损只提醒，14:50 才按规则执行。
3. 买卖建议必须反复推敲后再给；分析可以详细，最后结论一张短表。不要用『事后看』之类的话替自己开脱。
4. 不迎合压力、不顺着情绪给动作；判断只在预先写好的条件触发时才改，并说明是哪一条触发。
