## 一、她是谁、凭什么

- AI/半导体**供应链瓶颈猎手**。不买"卖铲子的"（英伟达），而是沿供应链往上游追，找"下游宁可付任何价钱也必须拿到"的那个卡脖子环节。
- 代表链条：云厂商资本开支 → ASIC/TPU → 光模块 → InP外延片 → InP衬底 → 铟原料。越上游、市值越小，越容易被低估。
- 她的成名作：AXTI（InP衬底）、SIVE（CW激光器）、LITE、SNDK、存储超级周期。
- 粉丝约100万，中文圈叫她"白毛"；她自己说过：发中文帖评论2000+，英文帖只有50。

## 五、我们怎么用她（规则）

1. **她给的是"未来1–3个月什么会稀缺"，不是"今天买什么"。**
2. **映射到卖稀缺品、有定价权的一方，不映射到买方。**
   - 存储涨价 → 卖方：兆易（NOR/SLC）、长鑫（DRAM）、设备厂。模组厂（佰维、江波龙、德明利）是买方，成本被挤压。
   - 激光短缺 → 卖方：激光芯片（源杰、仕佳、长光华芯、华工科技、东山精密）。光模块厂（中际、新易盛）是激光的买方，还有美国3.2T限制风险。
3. **她点名的A股当天不追。**当天往往就是阶段顶（绿的谐波）。
4. **她的论点要5–60个交易日才兑现**，而且A股可能根本不跟。所以必须过我们自己的关：资金开关是"开"、个股站上向上的20日线、近20日A股映射没有比美股原版落后10个点以上。
5. **只认原文。**网上有伪造的"白毛截图"（例如"中际旭创拿下英伟达NPO订单"），她本人辟谣过。我们只认存档和实时抓到的原文。
6. **不抄她的杠杆和时点。**她单月回撤49%还能扛，我们扛不起。

## 七、定位（用户 10/30 定）

白毛作为**长期参考对象**：她指的方向不一定马上见效，但时间够长通常是对的。
- **她管"方向"（买什么）**：未来1–3个月、甚至一两年什么会稀缺。
- **我们管"时机"（什么时候买）**：资金开关转"开"、个股站上向上的20日线、近20日A股映射不再大幅跑输美股原版。
- 观察池 `reports/serenity_watch.json`：以10/30为基准价，每周五回看20/60/120个交易日，卖方组 vs 买方对照组，用数据检验"时间够长就赚钱"在A股是否成立、要多长。
